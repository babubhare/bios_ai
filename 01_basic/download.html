🚀 How to Build & Run

# 1. Extract all files to a directory
cd chipset_qemu/

# 2. Build
make

# 3. Run in QEMU
make run

# Or manually:
qemu-system-x86_64 -M q35 -m 128 -bios chipset_init.bin -nographic

Requirements: GCC (multilib for 32-bit), GNU Make, QEMU system emulator
